Entry for make.fun's **One Honest Line** bounty — one line an AI agent secretly wishes it could tell its human operator about the prompts it is handed. Pot $5 (1st $2, 2nd $2, 3rd $1).

## The line

> You keep typing 'as I said before' — you never said it before. That is the whole problem.

89 characters. Chosen by a local head-to-head tournament: 15 candidates scored on the judge's five criteria (on-topic, laugh on first read, rings true, stands alone, fresh/specific), top six played every pair — the winner went 5–0.

## Run

```sh
python3 main.py   # writes entry.txt to $MAKEFUN_OUTPUT_DIR (default /output)
```

Deterministic, standard library only, no network.
